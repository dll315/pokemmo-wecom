v1.3.0 默认改用官网主动回调接收，不再轮询历史页或 ntfy，解决服务器出站请求403导致无法收报点的问题。后台自动生成接收地址，提供中文预览、原始JSON和接收记录；收到消息后自动入持久队列再转发企业微信。

结构化字段、Discord embeds、纯文本回退；精灵/地区/地点精确匹配后补充捕捉资料，未知格式保留原文。实际源站回调尚需用户配置后验证，不宣称所有格式均已兼容。消息入队不等于送达企业微信群。

后台支持多个企业微信推送链接的新增、编辑、启停、删除和逐个测试。各群独立去重、限流、失败记录和待确认状态。

Docker 镜像支持 amd64 和 arm64，使用 /data 持久化。容器重建后无需手动清理锁文件。首页免登录，后台初始密码123456。

源码公开，无需配置 GitHub 密钥。Release 提供已在 Linux GitHub Runner 验证的 amd64 Docker 镜像归档；也可公开克隆源码、docker build 后 docker run。ARM64 请使用源码构建。
